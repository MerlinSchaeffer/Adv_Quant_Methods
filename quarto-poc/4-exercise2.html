  1. Write it yourself: a coefficient plot. Fit co2 ~ income_level, tidy() it into a tibble, drop the intercept, and plot each coefficient with its 95% confidence interval (geom_pointrange() + coord_flip()).

tidy() gives you estimate, conf.low, and conf.high. Filter out "(Intercept)", then map estimate to y, the term to x, and add geom_hline(yintercept = 0, ...) as a reference line.

plotdata <- lm_robust(co2 ~ income_level, data = Dat) %>%
  tidy() %>%
  mutate(term = str_remove(term, "income_level")) %>%
  filter(term != "(Intercept)")

ggplot(data = plotdata,
       aes(y = estimate, x = reorder(term, estimate))) +
  geom_hline(yintercept = 0, color = "#901A1E", lty = "dashed") +
  geom_pointrange(aes(ymin = conf.low, ymax = conf.high)) +
  coord_flip() +
  labs(x = "Income group",
       y = "Average difference in CO2 (t per person)\nvs. low-income countries") +
  theme_minimal()

  3. Write it yourself: a prediction plot. Fit the bivariate model co2 ~ state_ownership, predict across a synthetic range of the socialism index, and plot the fitted line with its confidence ribbon. Mark two benchmarks with dashed red lines: a market-based economy (-1) and a state-run one (+1).

The index runs from about −3 to +2, so build fict_dat <- tibble(state_ownership = seq(-3, 2, by = 0.1)), then predict(ols_state, newdata = fict_dat, interval = "confidence")$fit, turn it into a tibble and bind_cols() it back. Plot with geom_ribbon() + geom_line().

ols_state <- lm_robust(co2 ~ state_ownership, data = Dat)

# Fictional countries spanning the observed range of the index
fict_dat <- tibble(state_ownership = seq(-3, 2, by = 0.1)) #<<
fict_dat <- predict(ols_state, newdata = fict_dat,

ggplot(data = fict_dat, aes(y = fit, x = state_ownership)) +

  1. Look at the two confidence intervals you just produced. Which is wider, and why?

A prediction is only as good as the data behind it. Most countries in Dat sit on the market-based side, so the model has seen plenty of them and its interval there is narrow. Very few countries score high on state ownership, so out there the same model is guessing from a handful of cases — and says so, honestly, with a much wider interval. This is exactly the widening ribbon you drew in the prediction plot, read as numbers instead.

(b) No. The figure is perfectly correct and still misleading on its own: it is drawn from a slope Exercise 1 showed is not robust, because the high-state-ownership end is populated by petro economies. (c) A positive slope is neither good nor bad by itself — it is the injustice that the low emitters bear the highest costs that turns the description into a research (and policy) agenda.
